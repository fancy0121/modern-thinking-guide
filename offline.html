# 隐私与记录

本站是免费静态网页，没有账户、广告、统计脚本或接收个人记录的后端。

- 你填写的事情和判断，仅在点击保存后写入本浏览器的localStorage。本工具不会自动上传这些文本。
- 本地保存是明文。同一设备和浏览器的其他使用者可能看到；浏览器清理、换设备或部分隐私模式可能导致记录丢失。重要记录请自行导出。

- GitHub Pages作为网页托管方可能记录访问者IP等安全访问日志。参见[GitHub Pages官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)。本站不宣称访问过程完全匿名。
- 清除按钮仅清除本工具在当前浏览器保存的记录，并要求确认；它不会清除导出文件、你给AI的内容或第三方访问日志。

不需要输入证件号码、账户密钥或与这件事无关的私人信息。只阅读指南完全可以不保存任何判断。
